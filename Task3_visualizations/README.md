# Task 3  Visualizations

## Dashboard

This project contains an interactive dashboard created using the Globel_superstore dataset.

## How to Open Dashboard

1. Download the `.pbix` file from this repository.
2. Install Power BI Desktop.
3. Open the `.pbix` file in Power BI Desktop.
4. Explore the interactive dashboard.

## Files

- Globel_superstore.pbix - Power BI dashboard file
- figure_1.png - Dashboard screenshot
- figure2.png - Dashboard screenshot
- Globel_Superstore_100.csv - Dataset used for analysis
